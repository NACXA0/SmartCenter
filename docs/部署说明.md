# SmartCenter 部署说明

终态架构：[架构-HAOS四App.md](../../docs/架构-HAOS四App.md)。密钥：[部署与密钥.md](../../docs/部署与密钥.md)。

## 推荐生产：HAOS

当前优先做完 **阶段①**（清单：[阶段1-HAOS底座验收.md](../../docs/阶段1-HAOS底座验收.md)）：

1. 刷 HAOS 到店内主机（N100 等），接 Coral  
2. Supervisor 安装：**Mosquitto**、**Frigate Full Access**  
3. HACS **Frigate Integration** + MQTT；侧边栏 iframe → Frigate  
4. 摄像头只进 Frigate `config.yml` / go2rtc；验收 MQTT `frigate/events`  

其后：

5. 阶段②：教室总控 **ESPHome**（[firmware/esphome/](../firmware/esphome/)：`home/<node>/door/*`）；`./firmware/esphome/START.sh` 或 `./START.sh flash`（Device Builder）；`lobn_office` 适配器 **mqtt**；HA `packages/door_mqtt.yaml`  
6. 阶段②附：RFID 通道防盗（默认 RS485 + 板载警号；HA `packages/rfid_asset_guard.yaml`）；见 [资产防盗-RFID.md](../../docs/资产防盗-RFID.md)  
7. 阶段③：`analytics-sidecar`；看板 iframe `:8080`（sidecar **不**承担 RFID 当场报警）  
8. 阶段④：排班 join、`business/access/grant`、云端桥接  

开发机可用本仓 `./START.sh start` 跑 HA + `lobn_office`，**不能替代** 店内 Frigate/ESPHome。

## 原则

- **不 fork HA 主干**：业务增量在 custom_components / 自动化 / sidecar App  
- **HA 零智能 / Frigate 零业务 / 总线即宪法**（见架构铁律）  
- 自研 SmartCCTV **不部署**

## 过渡期 `lobn_office` 选项

| 项 | 说明 |
|----|------|
| 云端 HMAC B | 仍要 |
| 旧监控 HMAC A/C | 归档后删除 |
| HTTP 门适配器 | 迁 ESPHome 后删除 |
| CCTV events HTTP 入站 | 改 MQTT / sidecar 后删除 |

## 验收要点

见主仓 [验收清单.md](../../docs/验收清单.md)。摘要：

- sidecar 全挂 → 保命开门仍可；RFID 本地比对仍响  
- Frigate 挂 → 识别自动停，保命可开  
- 停 HA → 软件开门停；ESP 按最后白名单仍可报警  
- FireClassroom 挂 → 资产防盗不受影响
