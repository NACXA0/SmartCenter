# SmartCenter 部署说明

## 原则

- **不 fork HA 主干**：业务在 `config/custom_components/lobn_office`。
- 升级：改 `pyproject.toml` / `VERSION` 中的 `homeassistant==x.y.z`，再 `uv sync`。
- Python：本钉选版本要求 `>=3.14.2`，用 uv 安装。

## systemd 示例

```ini
[Unit]
Description=SmartCenter Home Assistant
After=network-online.target

[Service]
Type=simple
User=smartcenter
WorkingDirectory=/opt/SmartCenter
ExecStart=/opt/SmartCenter/.venv/bin/hass -c /opt/SmartCenter/config
Restart=on-failure
MemoryMax=1G

[Install]
WantedBy=multi-user.target
```

## 密钥

| 文件/项 | 权限 | 用途 |
|---------|------|------|
| `config/secrets.yaml` | 0600 | HA secrets |
| 集成选项中的 HMAC | 仅配置库 | 监控上报 / 云端授权 / 人脸入库 三钥分离 |

```bash
chmod 600 config/secrets.yaml
```

监控与云端配置中**不得**出现 ESP32 开门 URL。

## 网络

- 内网：`smartcenter.lobn:8123`（Caddy 见 `LOBN_FireClassroom/deploy/Caddyfile.lan`）
- 云端：`cloud_base_url=https://fireclassroom.aleedu.com`（零入站，总控主动 HTTPS 拉授权）
- TLS：公网用 `Caddyfile.public`；办公室默认可明文内网

## 验收要点

- 停掉 SmartCenter 后，SmartCCTV 无法开门
- ESP32 超时 → `unknown`，不连发、云端不扣费
- 云端宕机时已注册人脸仍可开（热名单在内存）
- 监控宕机时已预取授权仍可开
