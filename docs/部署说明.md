## 推荐生产：HAOS

按阶段推进：

1. **阶段①底座**：刷 HAOS、Coral；Supervisor 装 Mosquitto、Frigate Full Access；HACS Frigate Integration（可选 Advanced Camera Card）；摄像头只进 Frigate；验收 MQTT `frigate/events` → [阶段1-HAOS底座验收.md](../../docs/阶段1-HAOS底座验收.md)  
2. **阶段②执行层**：教室总控 **ESPHome**（[firmware/esphome/](../firmware/esphome/)）；`lobn_office` 适配器 **mqtt**；HA `packages/door_mqtt.yaml`；可选 RFID → [资产防盗-RFID.md](../../docs/资产防盗-RFID.md)  
3. **阶段③智能层**：**SmartCenter Add-on**（[addon/](../addon/) Ingress 工作台）；Frigate **关 Face Recognition**；HA `packages/face_grant_mqtt.yaml`；刷脸 → `business/access/grant` → 门脉冲 → [人脸-SmartCenter-Add-on.md](../../docs/人脸-SmartCenter-Add-on.md)  
4. **阶段④扩展**：利用率看板、取证 rclone（不阻塞刷脸上线）

开发机：`./START.sh all`（Vite + API reload + 本机 HA），**不能替代** 店内 Frigate/ESPHome/Coral。

## 本仓结构对照

| 路径 | 部署角色 |
|------|----------|
| `config/` | 同步到 HAOS 配置；含 packages + `lobn_office` |
| `config/packages/door_mqtt.yaml` | 店员保命开门 |
| `config/packages/face_grant_mqtt.yaml` | grant → 门脉冲 |
| `config/packages/rfid_asset_guard.yaml` | RFID 白名单/通知 |
| `addon/` | Supervisor 本地 Add-on（人脸控制面） |
| `addon/web/` → `addon/app/webui/` | 工作台源码 / 构建产物 |
| `firmware/esphome/` | 生产教室总控固件 |

## 原则

- **不 fork HA 主干**：业务增量在 custom_components / 自动化 / Add-on  
- **HA 零智能 / Frigate 零业务 / 总线即宪法**  
- Add-on **无自建登录 / 无 RBAC**（Ingress 即管理员）  
- 自研 SmartCCTV **不部署**；Frigate **不做**开门用人脸库  

## 过渡期 `lobn_office` 选项

| 项 | 说明 |
|----|------|
| 云端 HMAC B | 仍要（小程序开门队列等） |
| 旧监控 HMAC A/C | 归档后删除 |
| HTTP 门适配器 | 迁 ESPHome 后删除 |
| CCTV events HTTP 入站 | 改 MQTT / Add-on 后删除 |

## 验收要点

见主仓 [验收清单.md](../../docs/验收清单.md)。摘要：

- Add-on 全挂 → 保命开门仍可；RFID 本地比对仍响  
- Frigate 挂 → 刷脸自动停，保命可开  
- 停 HA → 软件开门停；ESP 按最后白名单仍可报警  
- FireClassroom 挂 → 资产防盗不受影响；已采集本地仍可比对（停用以云端为准）  
- Ingress 四页与 `/data` 容量策略正常
