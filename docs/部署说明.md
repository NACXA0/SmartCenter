# SmartCenter 部署说明

终态架构：[架构-HAOS四App.md](../../docs/架构-HAOS四App.md)。密钥：[部署与密钥.md](../../docs/部署与密钥.md)。

## 推荐生产：HAOS

1. 刷 HAOS 到店内主机（N100 等），接 Coral  
2. Supervisor 安装：**Mosquitto**、**Frigate Full Access**、（阶段③）**analytics-sidecar**  
3. HACS 安装 **Frigate Integration**；配置 MQTT  
4. 摄像头只进 Frigate `config.yml` / go2rtc  
5. 门板刷 **ESPHome**，订 `home/<door>/command`，报 `state`  
6. HA：保命自动化（`business/access/grant` → command）；侧边栏 iframe → Frigate `:5000`、sidecar `:8080`  
7. 云端：`cloud_base_url` + 密钥 B；店主动 HTTPS  

开发机可用本仓 `./START.sh start` 跑 HA + `lobn_office`，**不能替代** Frigate/ESPHome 生产路径。

## 原则

- **不 fork HA 主干**：业务增量在 custom_components / 自动化 / sidecar App  
- **HA 零智能 / Frigate 零业务 / 总线即宪法**（见架构铁律）  
- 自研 SmartCCTV **不部署**

## 过渡期 `lobn_office` 选项

| 项 | 说明 |
|----|------|
| 云端 HMAC B | 仍要 |
| 旧监控 HMAC A/C | 归档后删除 |
| HTTP 门适配器 | 迁 ESPHome 后删除 |
| CCTV events HTTP 入站 | 改 MQTT / sidecar 后删除 |

## 验收要点

见主仓 [验收清单.md](../../docs/验收清单.md)。摘要：

- sidecar 全挂 → 保命开门仍可  
- Frigate 挂 → 识别自动停，保命可开  
- 停 HA → 软件开门停
